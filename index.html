ScriptShare

 

One-time setup

ScriptShare saves your script to your private GitHub repo . It needs a GitHub key (a "token") that only works on that one repo.

Open GitHub: create token ↗
  1. The link fills in the name, 1-year expiry and Contents: Read and write for you. (If it doesn't, set Repository permissions → Contents → Read and write.)
  2. Repository access: choose "Only select repositories" and pick .
  3. Tap Generate token, copy it, come back here and paste it below.

The token is kept only on this device (in this browser's storage). It's never sent anywhere except GitHub.
